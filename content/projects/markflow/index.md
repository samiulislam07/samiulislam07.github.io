MarkFlow is a real-time collaborative Markdown editor with AI-assisted content drafting.

<!--more-->

## Features

- **Real-time collaboration**: multiple users edit the same document with live updates.
- **AI-assisted drafting**: generate and refine content directly in the editor.
- **Live Markdown preview** alongside the editor.
- **Role-based access control (RBAC)** for owners, editors, and viewers.

## Stack

Next.js, MongoDB, and REST APIs, built with attention to scalability and a clean system architecture.
